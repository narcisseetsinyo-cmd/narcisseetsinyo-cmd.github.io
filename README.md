# Narcisse Etsinyo

Site vitrine et blog de Narcisse Etsinyo : assistant de direction, communicant, photographe et graphiste à Lomé, Togo.

Publié avec GitHub Pages (Jekyll) : https://narcisseetsinyo-cmd.github.io

- `index.html` : page d'accueil
- `_posts/` : articles du blog. Voir **PUBLIER-UN-ARTICLE.md** pour en ajouter un.
- `assets/img/blog/` : photos des articles
- `cicart/` : application CIC'ART
